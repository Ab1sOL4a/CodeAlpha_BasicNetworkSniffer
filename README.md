# Basic Network Sniffer

A Python-based network sniffer developed using Scapy to capture and analyse network traffic.

## Project Overview

This project demonstrates the basic process of capturing network packets and examining their structure and content.

The program displays useful information from captured packets, including source and destination IP addresses, protocols, ports, packet size, TCP flags, and available payload information.

## Objectives

- Capture network traffic packets using Python.
- Analyse the structure of captured packets.
- Identify basic network protocols.
- Display source and destination IP addresses.
- Display protocol and port information.
- Examine available packet payloads.
- Improve understanding of how data flows through a network.

## Technology Used

- Python
- Scapy
- Networking protocols
- Wireshark for optional packet analysis

## Features

- Real-time packet capture
- IPv4 and IPv6 packet analysis
- TCP analysis
- UDP analysis
- ICMP analysis
- ARP analysis
- Source and destination IP identification
- Port identification
- Payload preview
- Packet size information
